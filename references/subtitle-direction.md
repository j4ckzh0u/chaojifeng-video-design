# 字幕导演与配色

字幕既承担内容，也参与声音和画面的节奏。适用于有旁白、歌词或用户要求字幕的视频；音乐场景与 [音乐镜头与运动编排](music-shot-choreography.md) 一起使用。保持引擎中立，复用项目可编辑文字层与唯一时间轴，不增加必填合同或固定动效参数。

## 语言与内容

- 用户明确指定字幕语言、仅英文、无字幕或已有项目字幕规则时优先遵循。没有指定且存在旁白或歌词时默认双语：中文为主，英文为辅；用户明确要求英文时纯英文。不是因为原歌为英文就自动推断用户要求纯英文。
- 以用户提供或实际音频可核实的唱词、旁白为依据；翻译忠实、自然、简洁，核对术语、语气与画面语境，不为押韵或节拍改变原意。纯器乐不虚构歌词，适合留白时保持留白。
- 优先复用可信逐字稿和已有时间标记；需要时转写、对齐并核对实际音频。记录用户提供、人工核对、自动识别、估计等依据；识别结果不是自动通过。无法核准唱词或翻译时说明具体缺口，不编造、不静默省略必要字幕；只交候选并标注未完成。

## 有演唱时先建立歌词时间线

在锁定依赖歌词含义的分镜前，完成以下步骤；无歌词的器乐段单独标记，不生成虚构唱词。用户明确无字幕时仍需理解真实演唱，但无需制作字幕轨。

1. 先找本任务已有逐字稿、用户唱词和对齐结果，核是否对应实际版本、选段和音源。只有纯文本歌词时仍需对齐，不能按字数均摊时间。
2. 没有可信时间稿时，沿 [音频能力检测与按需安装](audio-capability-setup.md) 探测已有 ASR／对齐能力，并在任务权限与资源内短样验证。Whisper、ACE-Step 1.5、HTDemucs 按转写、理解／生成、可选分离职责独立选择，先复用环境和结果；缺失时给对应官方安装入口，只补本任务所需组件。首次启动或加载可能触发模型下载，不能当作只读检测。新服务上传、收费或大型模型安装遵循宿主授权和资源约束；已授权范围内继续，不为填表自动全装。不可用时记录具体能力缺口，不能仅写“用户没提供歌词”。
3. 对照真实音频校对重复唱句、拖音、漏词和识别不确定处。歌唱转写结果保持候选；已有可信唱词可用于校正与强制对齐，但对齐结果仍需核验。无法听审时如实保留未听审范围。
4. 在项目内保存机器可读的带时间戳稿（JSON 或支持所需精度的字幕格式），至少记录音源身份、源区间、源到成片时间映射、句 ID、唱词、起止时间、方法和核对状态；可以用配套说明保存格式无法容纳的元信息。逐字／逐词跟唱另需可信词／字级时间；句级稿只支持句级同步，英文翻译沿原唱句安排阅读，不冒充英文实际演唱。
5. 歌词时间线与音乐事件地图分别提供语义和节奏依据，再汇入项目唯一排程。未完成的识别区间可以先做不依赖唱词的画面探索，但必要字幕与歌词相关镜头不得据猜测验收。失败时保留尝试记录、受影响区间和补救路径，交付状态为候选／未完成，不能静默改成无字幕成片。

## 先编排视线，再选择字幕版式

音乐视频在分镜阶段就同时设计场景、镜头和文字。语言默认不等于位置默认；优先探索文字怎样参与当前场景，不预设整片采用底部居中双行。固定阅读版式继续适用于密集内容、稳定阅读、用户指定或当前镜头的表达需要。自由编排不要求每句换位置，也不以花哨程度验收。

沿既有事件卡完成“语义单元 → 场景锚点 → 出现与强调 → 可读停留 → 焦点交接”。一句可以拆成词或词组，但保留语义顺序、否定与修饰关系；不把一个词拆散后改变含义。说明此时观众先看哪个对象或词组，何处接续，何时需要看完整句意。前一单元可停留、减弱、移出或与后一单元组合，不能让多个角落同时争抢阅读。

文字可主动引导镜头、揭示意象或成为主要视觉事件，也可承接主体动作。主导权在场景、文字与镜头之间按表达需要交接；让位的是当前无关的运动，不是永久压低文字。

双语字幕默认将英文紧贴对应中文下方，形成清晰可辨的阅读组；整句布局按句配对，中文拆成词组时优先把忠实、自然的对应英文短语放在各词组下方，并与该词组一起进入、移动与退出。不要为了逐字配对破坏翻译或改变语义；不适合拆分时可将英文完整短句紧贴整个中文语义组下方，并保留充分阅读时间。中英文在动态画面中保持近距离、稳定对应、可读间距和适当层级，避免分置于相距很远的画面区域、互相遮挡或裁切；不必强制中英逐字同步。用户明确指定其他版式或语言时遵循其要求。

### 可自由组合的编排方向

以下为本库的设计归纳，不是封闭模板库或必须逐项使用的效果清单。Agent 可组合、变形或自定义适合歌曲的方式。

| 方向 | 文字与画面的关系 | 需要看清的结果 |
| --- | --- | --- |
| 词组接力 | 一句内的词组依次在不同视线落点出现，通过位置、字号、色彩或运动交接 | 观众顺着动线读完句意，不用在多个角落寻找下一词 |
| 意象锚定 | 词组靠近对象、轮廓、空位或人物视线，按需要随主体或镜头移动 | 文字位置解释关系；附着、遮挡与跟随符合场景空间 |
| 语义动作 | 用距离、延展、聚散、分离、回退或形态变化表达情绪 | 动作有语义目的，变化后仍能读懂文字 |
| 文字运镜 | 词组构成空间层次，镜头推进、转向或穿越，使下一单元进入视野 | 路径与阅读顺序可追踪，运动后有稳定阅读窗 |
| 声音重音标点 | 字号、字重、颜色或形态的变化峰值抵达真实声音锚点 | 强调有主次，长音和停顿也能组织变化，不强迫每拍闪动 |
| 文字与场景接棒 | 文字先引出期待，镜头随后兑现；或主体先行动，文字揭示含义 | 主焦点与下一焦点明确，文字和场景共同推进事件 |
| 固定阅读版式 | 稳定双语行或单语行，按句组织强调与进退 | 信息密集时仍读得完；它是可选表达，不是音乐视频的唯一默认 |

句内拆分与空间移动可以作为设计选择，但只有可信词／字级时间才能宣称逐词／逐字跟唱。只有句级时间时，标明句内变化为非精确对齐编排，不能按字数均摊或伪造时间精度。切换镜头时还要说明前一阅读单元如何结束、保留或延续，不能让转场截断必要语义。

## 音乐与动作

1. 沿既有音乐事件表与项目唯一时间轴，映射源音频到成片时间，确定唱句、停顿、呼吸、重音、旋律及情绪变化；换音轨或变速后重新核查。机器检测只是候选，未听审不称实测卡点通过。
2. 按乐句决定字幕出现、完整可读、强调与退出，并与主体动作、镜头切换和画面焦点协调。字幕可以在句首、声音落点前后出现，按表达意图留阅读窗；英文作为辅助层，不能过小或被主字幕遮挡。
3. 有可信词级时间时可采用重点词逐个点亮或跟唱；只有句级证据时做逐句同步或句内非对齐强调，不伪造逐字时间。关键词选择服务语义，避免全句都上强调色。
4. 按歌曲与镜头选择词组重组、空间位移、尺度对比、文字运镜、遮罩揭示、长音延展、图形呼应或克制的渐显等；高潮可增强，低声或停顿可克制、留白。进退场和特效不得盖过唱词、遮挡主体、破坏阅读或强迫每拍闪动。实际动作由项目实现，并在连续播放中验证。
5. 动态版面适配横竖画幅与目标播放尺寸；保持安全边距，检查换行、字体、语言字形、长句及背景变化。用户或平台的字幕需求优先；必要时使用渐变底、描边或阴影，确保字幕与背景区分。

## 实际验收与来源

先复用开场短段，并补一个拆词、空间移动或背景复杂的高风险字幕段做内部预演；direct 模式不增加用户确认门禁。查看实际导出的开头、长句、强调、字幕切换、背景复杂处和结尾，核字幕实际存在、双语层级、翻译、裁切、对比、遮挡与阅读时间；连续播放并听真实声音，检查唱句起止、强调与音乐落点。在目标播放尺寸、正常速度下核对完整句意、阅读顺序、稳定停留、英文是否紧贴对应中文、各组动态中是否保持对应及焦点交接。静帧清晰不代表运动中读得完；出现追字困难、语义截断或装饰抢焦点时，先改分组、停留与交接，再调整装饰参数。技术检查、抽帧、完整观看、听审分别记录；无法听审保持 partial/not_run 并列待检范围。发现漏字幕、错词、明显错位或不可读先修复；无法完成时说明阻塞与受影响范围。

参考用户提供的本机三角函数音乐视频：其字幕独立编排，中文主行、英文辅行、重点词暖红，逐句进出且间奏留白；其源码为中文 `#F5F0E8`、英文 `#B0B0B0`、重点 `#E85D5D`，词级跟唱未在该案例中实现。此处 `#D8716D` 是用户指定的另一参考色。案例源代码与抽帧仅证明对应实现与画面，未将案例听审状态或同步结论转移到新作品；私有对话和素材不纳入分发。
