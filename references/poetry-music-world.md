# 诗词、乐器与三维意象

在音乐驱动流程中，需要让唱词、乐器与景物共同表达时加载本页。先沿 [音乐驱动三维世界](music-driven-world.md) 取得当前音轨和有效事件，再安排意象、空间与表演。不因出现古诗就强制加入人物或琵琶。

优先复用已有诗词工程。`music_world.py init` 仍使用 ink、rain、concept 及已声明的别名；诗词意象是制作分支，当前 Agent 需在合适的基础配置上实现人物、乐器、笔画和运动映射，通用起步几何不代表这些主题内容已经完成。

## 从语义建立接力

先写清一条能被看见的因果链。例如琴弦接触产生水波，水波延伸成笔触，笔触形成诗字，诗字的遮挡或运动把镜头交给下一处景物。每一环说明前态、触发、可见结果与接续对象；新诗、新乐器与新主题重新选择载体。

诗字可以有体积、材质、笔锋与空间方向，也要保留辨认窗口。沿字的笔画顺序揭示，提前计算运动终点和尺度，让接触、击中、峰值、落定分别落到有效事件。字与人物、琴、舟和镜头的空间关系来自同一排程；避免不同脚本各自维护一份击中时间。

世界中的诗字负责空间叙事，屏幕底部字幕负责完整唱词。二者分别排版；动态大字不能替代逐句量时的稳定字幕。采用实测唱词、原文与来源，识别缺口和估计字时间单列。

## 声音时钟与运动时钟

音轨、字幕和起音事件使用整片绝对时间 t；连续运动使用从 t 积分得到的世界时间 τ。镜头需要独立速率时也从同一个 t 派生。曲线形状、速度和停顿区间属于本片编排，不照抄案例常量。

| 内容 | 时间依据 | 检查重点 |
| --- | --- | --- |
| 演唱、字幕、真实起音与事件触发 | t | 当前音轨区间、字音、击中时刻 |
| 弦振、舟船、水面、衣袖、发丝和环境运动 | τ 或明确的派生时钟 | 收住与释放是否同时发生，恢复后是否连续 |
| 镜头行进、微晃与事件推进 | 从 t 派生的镜头时钟与事件 | 音乐收住时是否仍在漂移，击中前是否已到位 |
| 辉光、颗粒等后期 | 帧号与事件 | 停顿时是否仍有无意闪动，切点前后是否稳定 |

先区分完全静止和接近静止的艺术处理。案例采用低速率收住，不是所有运动严格归零。实现中逐项检查仍用真实时间或独立循环驱动的物体；不能只把相机停下就声明整个世界已凝住。释放时从累积状态连续恢复，避免跳回默认姿势。

有真实弹拨与人声分轨时，可按事件分别核起音；密集连贯音乐的阈值检测可能漏检。保留检测方法、容差和未检出项，结合关键时刻前后帧与实际听审判断。整片音量和运动的相关系数不能替代逐点声画核验，也不能证明文学表达或演奏真实。

## 人物与乐器共同表演

需要人物时，先按 [场景与工具组合](scene-tool-composition.md) 复用合适资产，并检查来源和许可。先建立琴与人的局部坐标、坐姿、握持和接触目标，再求手臂与手指动作；相机或舟船移动后保持这些相对关系。

按真实动作划分准备、拨弦接触、回弹、换位与停留；右手、左手、腕、肘、肩、头与衣袖分别承担明确职责。动作幅度由演奏、机位和节奏决定，不能用无目的的整体摆动表现“在弹奏”。数值检查用于找穿模、脱离接触和关节突跳；近景、侧面、越肩与实际入镜机位还要连续看。

脸型、眼睑、虹膜、皮肤、发际和服饰按本片目标检查。网格数量、骨骼数量、关节距离或一次静帧不能证明自然，也不能证明人物已经符合用户的审美要求。人物仍有塑料感、动作僵硬或待修意见时，分别记录，不将已导出的版本记成已获认可。

## 分层外观、成本与复验

先锁定语义、接触与时刻，再调整月光和灯火、空气透视、水面反射、材质、辉光和镜头。外观层保留独立强度或开关，用同机位、同曝光与同一组动作比较；增加亮度和效果数量不能替代改善。

镜头硬切附近检查运动模糊的跨镜污染。保存工程的回读可能需要前置帧才能重建运动信息；按实际执行器验证所需预热，不把一次随机跳帧或同机复现推广为所有机器上的一致性保证。

优先复用已渲染帧、母带、字幕与音轨。先用会入镜的关键机位与最难接触窗口检查，再按资源上限串行渲染；只改合成和文字时沿现有帧继续，不重做整个人物与世界。

交付保留音轨身份、时间映射、事件、可编辑源、依赖与素材出处。机器对齐、抽帧观察、连续观看、听审与用户认可分开记；新音轨、人物、镜头或素材版本不继承旧版通过状态。

## 本库实践

《琵琶行·江月》采用 Blender Python 构建江面、琴弦、舟船和立体诗字，由 Remotion 组织音乐、笔画和稳定字幕；人物底模使用有来源记录的 CC0 资产，细节、衣发与表演继续在工程中适配。它为意象接力、派生时钟、分层外观和接触检查提供实践材料，不是人物自然度已通过的范例。

公开15秒片段来自已交付 v3 的23.5–38.5秒，保留《琵琶行》原歌曲选段；人物精修仍有后续版本，案例版本及媒体哈希记录在 [作品清单](../assets/gallery/originals.json)。歌曲与外部资产的权利分别见 [来源说明](../THIRD_PARTY_NOTICES.md)。该案例的逐点测量和同机复现只能支持对应条件，不能替代新主题的实际审查。
