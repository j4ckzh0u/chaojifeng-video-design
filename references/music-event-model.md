# 音乐驱动的声画事件模型

音乐主导画面时，与 [歌曲视觉导演](song-visual-direction.md)、[镜头编排](music-shot-choreography.md) 配合使用。核心判断是：音乐带动了什么可见事件，这个事件怎样改变观众的感受？六层判断汇入同一份 [音乐导演笔记](../templates/music-direction.md)，复用工程排程，不新增必填 JSON、效果配额或第二套时间轴。用户明确的静态、长镜、无字幕、原声及交付约束优先。

## 1. 音乐时间线：区分段、句、瞬间

核实际音源，有演唱先取得并校对歌词时间线。歌词说明唱了什么，音乐事件说明何时怎样推动画面，两者共同支持剧本。

| 层级 | 标记什么 | 可驱动什么 |
| --- | --- | --- |
| 段落 | 进入、积累、转折、释放、余韵；以实际曲段为准 | 场景关系、空间尺度、整体运动与情绪走向 |
| 乐句 | 唱句起落、换气、长音、旋律转折、乐器进入或退出 | 动作过程、镜头推进、注意力转移与接力 |
| 瞬间 | 重音、停顿、明确瞬态或经核实的拍点 | 切点、接触、揭示、动作峰值与重点词强调 |

每个有效锚点关联源时间、成片时间、声音特征及证据状态，引用既有 cue sheet／score。无需给每拍填卡；慢歌仍从唱句、呼吸、旋律和停顿组织事件，不能让全片只跟单个 BPM、音量曲线或无关循环运动。信号候选不冒充听审，换音源后重验映射。

## 2. 情绪与事件：明确前后改变的关系

先写主体正在经历什么、向什么靠近或远离、这一段结束后关系有何不同，再选意象和风格。可以是人物行为、物件互动、空间距离或抽象形态的发展，不强加人物、冲突或三幕。靠近却错过、重复动作终于改变、完整逐渐缺失只是构思方向，不是固定剧情。

为主要意象明确三件事：它与本曲情绪或语义的关联，画面中建立关联的可见线索，后续变化如何发展这层关系。关联可以来自行为、使用痕迹、空间距离、视线或形态变化；不要求字面翻译歌词，也不要求观众猜出唯一解释。导演笔记里写了“物件代表某个人”还不够，关键关系必须在实际画面中有依据。若关联只能靠解释成立，先补建立关系与后果的镜头，或换更有效的意象，不靠加雨、改色温或换装饰补救。

同一意象重复时发展状态或含义。环境循环可以维持氛围，但不能独自证明叙事推进；换背景、换机位、增加雨量也不自动构成新事件。用户明确要强视觉、律动与镜头变化时，关键段落必须有在正常播放中可辨的行动、揭示或关系变化。情绪适配是创作假设，实际共鸣仍需观众反馈。

## 3. 镜头与注意力：先写观众会看见什么

关键镜头先写“先看哪里 → 什么引导视线 → 最后发现什么”，再选景别、机位与运动。说明移动带来的视差、遮挡揭示、尺度变化、焦点转移或跟随关系；二维平移、缩放同样可用，但 camera／scale 参数变化不能代替运镜感的证据。

在目标观看尺寸、正常速度下检查主体与变化是否清楚。可通过放大主体、建立前景参照、调整遮挡、动作幅度或剪辑位置加强表达，不规定通用位移百分比或切镜次数。每个关键事件明确当前主焦点与下一焦点，由场景、文字或镜头按需要领衔，其他运动让位或辅助。字幕可以主动揭示、牵引视线或参与动作峰值；在分镜草图中安排词组锚点、阅读窗与交接，沿 [字幕导演](subtitle-direction.md) 实现。下一镜通过视线落点、方向、动作、形状或语义承接。

信息流开场按 [开场设计](opening-design.md) 明确首帧焦点、前三秒可辨事件、声音入口与后续兑现。可以动作中进入、揭示空间、先显结果或建立关系悬念，自主选适合歌曲的方式；不要把三个阶段机械切成每秒一个镜头。保留用户要求的前奏，在前奏内部设计视觉推进。三秒是检查窗，不是爆款保证。

## 4. 动作与卡点：峰值抵达声音

按事件需要安排“准备 → 加速／积累 → 抵达、碰撞或揭示 → 回落与后果”。标清哪个阶段对齐哪个声音锚点，以及有意提前或延后的理由；不要只核动画启动时刻。一次主要动作可跨多个拍点，字幕、环境和次运动按职责错开，不要求每层每拍同时响应。

用近与远、动与停、密与疏、遮挡与显露形成可辨对比；强弱来自事件之间的关系，不用持续最大速度或整片匀速替代设计。检查长音推进、换气接力、重音落定等选择是否由本曲支持，不把这些对应当固定公式。切镜、动作峰值和情绪变化分别验证，时间一致不等于体验成立。

## 5. 材质与空间：让效果属于场景

为承担主动作或显著占画面的效果说明：它位于哪层、附着在哪里、受什么驱动、与谁遮挡或发生作用。选择写实或风格化表现；写实依据可观察的空间和材质关系，风格化保持自己建立的规则，无需为每种风格强加物理模拟。

例如雨可能在空中、附着玻璃或以光影投到墙面：空中雨与场景深度和遮挡相关；玻璃水滴需有附着、滑落等可读特征，折射按所选表现方式处理；墙面雨影由投影和光线关系成立。不能不分层地贴一组循环线条就宣称完成雨景。这个例子用于检查空间，不将雨窗设为情歌默认场景。

先用低成本短段验证关键材质、相机和主体动作。若无法兑现，保留情绪与事件目的，调整素材、资产、镜头或实现路线；不要重复微调坐标而回避失败。沿已有能力分工选工具，不以使用 Blender、Three.js、Remotion 的数量验收。

## 6. 感知验收：预期与实际分开

预演先覆盖开场和首个关键声音落点，再按风险补复杂字幕、转折、材质和转场；能共用短段就复用。direct 模式内部检查、返修后完成整片，不增加用户试片确认。先独立描述实际看到的变化，再与事件卡对照；同一 Agent 执行时明确是自检，不能模拟独立观众。

| 检查 | 要留下的判断 | 不足时优先调整 |
| --- | --- | --- |
| 正常尺寸、正常速度看开场 | 主体、实际事件、继续观看的理由、后续兑现位置 | 焦点、进入动作、揭示顺序和声音入口 |
| 临时隐藏字幕诊断画面 | 场景或动作本身传递什么；是否全靠歌词解释变化 | 行为、空间关系或视觉线索；歌词型作品保留其文字职责 |
| 声画连续回放 | 重要切点、峰值、回落与声音是否相接；是否机械跟拍 | 动作阶段、峰值时刻、主次运动与阅读窗 |
| 正常速度阅读动态文字 | 完整句意、词组顺序、可读停留与焦点如何交接；双语是否完整 | 分组、空间锚点、阅读窗及交接；保留适合当前段落的固定版式 |
| 比较相邻段落 | 关系、景别、空间、动作或情绪怎样推进 | 事件后果、跨镜接力与强弱对比 |
| 检查材质与空间 | 附着、遮挡、反射、光影与运动是否一致 | 图层归属、资产或实现路线 |

没有观看能力保留 visual／playback 缺口，没有真实听审保留 audio 的 partial／not_run；抽帧、源码、参数或结构通过不能升级为连续观看、旋律同步或共鸣通过。适配、同步、感动与平台留存分别记账，无观众或平台数据时后两项不宣称已验证。沿 [审片流程](review-and-revision.md) 限定返修资源与停止条件；必要表达未兑现时先返修，仍受阻则交候选及具体缺口。

## 来源与证据边界

2026-10-29 核对以下资料；六层模型、事件卡与检查方法为本库的设计推导，不是任一论文原有完整框架，也未做本模型效果实验。

- [TikTok Creative Codes](https://ads.tiktok.com/business/en/creative-codes)：读到官方页面关于 hook/body/close、悬念／惊讶／情绪、运动／转场与声音的广告指导。嵌入视频未成功播放；Top Ads 可见样本主要为广告，未完成音乐爆款逐镜头与真实听审，不能声称证明自然流量或抖音效果。
- [Magliano 与 Zacks，2011](https://pubmed.ncbi.nlm.nih.gov/21972849/)：读取原始研究摘要；参与者观看商业电影并分段，结合 fMRI，动作不连续对行为事件分段影响最大，时空不连续影响较小。支持重视有意义事件的设计方向，不证明某种镜头数或强刺激能提高留存。
- [Lin、Yeh 与 Shams，2022](https://pubmed.ncbi.nlm.nih.gov/35398533/)：读取原始研究摘要；操纵视频切点与伴奏节拍对齐，一致条件下感知愉悦度更高。扩展到动作峰值是本库推导，不把切镜实验泛化为所有动效、所有曲风的保证；本轮未核效应量或全套实验细节。
- [Fink 等，2024](https://www.nature.com/articles/s41598-024-71399-y)：读取开放论文的摘要、设计和相关讨论；201 人、16 件作品，比较单模态及作者搭配／随机搭配的声画条件。作者搭配的匹配感更高，但其他主观评价与停留时间无显著差异；视觉艺术配乐场景不能直接当运动音乐视频结论。用于提醒匹配、感动与停留不可互相代替。
- [Filmmaker 对 Walter Murch 方法的介绍，2016](https://filmmakermagazine.com/100389-watch-walter-murchs-six-criteria-while-editing/)：读取介绍文字，强调情绪、故事及引导视线；未完整观看内嵌访谈，不声称完成原访谈听审，不写未经验证的权重公式。

相关性依声画同步、事件理解与开场设计判断；平台资料只在其广告语境内引用，基础认知研究保留年代与实验范围，不因旧而直接废弃。未保存可比的访问、点赞或评论口径，统计视为未知，不据互动量给方法背书。原有 [耶鲁教学资料的灵感署名](song-visual-direction.md#方法来源) 保留。
