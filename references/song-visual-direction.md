# 从歌曲到视觉体验

用于歌曲主导的音乐视频。用户只提供歌曲时也可进入：在授权和实际素材范围内，由 Agent 理解歌曲、自主选择视觉方向并继续制作；用户指定的故事、风格、音乐版本和交付方式优先。简单任务将判断写入已有计划，不额外制造文档或确认节点。只有必要音源、事实、素材或费用确实阻断才说明缺口。

## 先理解，再决定怎样呈现

1. 核实实际音源、版本、可用选段和时长；有演唱时先按 [字幕导演](subtitle-direction.md) 取得带时间戳的歌词稿，作为歌词相关剧本与字幕的基础。复用可信稿或尝试实际可用的 ASR，再核对唱词、乐句与对齐；未核准部分保留待检，不先按猜测定稿。回听并标出重要乐段、重音、停顿、旋律走势与情绪变化；机器分析是候选，不冒充听审或已核实拍点。音源不可用或无法听审时明确缺口，不凭歌名断言旋律、歌词或作者本意。
2. 分开记录歌曲明确给出的意象与语境、情绪及关系的变化、音乐本身的运动；标记自己的解释和拟采用的创作隐喻。歌曲可能同时包含具体意象和抽象情绪，不强行二分。已有意象先探索它的关系和变化；意象较少时可从人物、空间、物件、色彩或抽象运动创造视觉线索，不编造歌曲的确定背景或作者原意。
3. 定义观众期待的感受、可能的情绪变化和贯穿线。允许细微、持续或有意静止的体验，不强制完整剧情、人物冲突、转折或大高潮。依据实际曲段选择一处或少量值得记住的时刻，写清之前、变化、之后与声音职责。
4. 分别选择呈现方式、视觉语言与声画关系。概念型可围绕隐喻或视觉规则，表演型以演唱、演奏、舞蹈等为主体，叙事型通过事件或关系推进；可混合，也可用歌词或抽象视觉为主。这些是启发式选择，不是互斥分类或固定比例。
5. 根据歌曲、受众、用户约束、已有素材、实现能力和资源选择风格，记录理由；先查本库风格画廊与目录，必要时组合或在项目自由设计。不要凭曲名、曲风或民族标签把歌曲绑定水墨、雨窗或某种色彩；现有包是指导或参考，不等于已在本片渲染、审听或获得素材授权。新风格候选不自动登记为已完成风格包。
6. 按 [声画事件模型](music-event-model.md) 的六层判断进入 [音乐镜头与运动编排](music-shot-choreography.md)：区分段落、乐句与瞬间锚点，先写事件改变了什么，再确定注意力、运镜、动作峰值、材质空间和验法。用户要求律动、镜头或动效变化时逐项检查实际兑现。长镜和克制表达需有具体音乐理由与可辨发展，不凭慢歌自动收缩为单一空镜。

## 导演式构思与开场

音乐带动画面的节奏，歌曲营造氛围；画面通过场景、动作、空间关系、镜头和动效吸引观众进入。先在现有计划或 [音乐导演编排模板](../templates/music-direction.md) 留下以下决策，再进入完整制作。这些是 Agent 的内部工作，不增加用户确认节点。

- **一句视觉主线。** 写本片发生的变化和观众期待的感受，区分真实唱词、歌曲语境与自创隐喻。把歌词当理解材料，镜头可以延伸、对照或补充含义，不按每个名词逐字配图，也不把歌词复述当剧本。
- **场景能发生事情。** 定义空间、主体、物件和关系，再写前态→动作／揭示→后态。需要具体表达时加入人物行为、物件互动、空间阻隔或距离变化；无人物或抽象方向仍须有形态、关系和结果的演进。雨水、雾、粒子可承担环境或主动作，但不能自动替代场景发展。
- **情绪与运动曲线。** 随真实曲段安排蓄势、推进、释放和余韵，允许非线性与微妙变化。标明各段镜头距离、主体运动、相机速度、切换密度和动效力度如何变化；不要求每段全改，也不以整片匀速推镜应付慢歌。
- **首帧与前三秒。** 信息流音乐短片默认设计开场：首帧把注意力放在哪里，前三秒发生什么可辨事件，它与实际声音入口怎样对应，后续如何承接。可比较动作中切入、空间／尺度揭示、关系悬念、结果先显等适合本曲的候选，再自主选用；不必强塞标题、口号、闪光或快切。用户要求完整前奏时保留音源，在前奏里编排视觉事件。
- **记忆点与接力。** 为值得突出的乐句设计可记住的视觉事件，明确其铺垫和后果；同一意象再次出现时发展关系或含义。丰富度来自有目的的变化，不是固定数量的地点、镜头或特效。

“前三秒”是本库的短视频设计检查窗，不是已验证的爆款定律。没有实际观众／平台反馈时，吸引力与共鸣仅记导演判断及待验证假设。保留 [耶鲁音乐视频教学资料](https://teachers.yale.edu/download/units/12_01_05.pdf) 的方法来源说明；这里的开场与执行要求属于本库扩展。

## 场面与声音共同导演

选择真正服务本片的维度，定义其如何随乐段发展：场景与物件承担什么；造型和材质呈现什么；光线与色彩如何引导注意；主体、物件和镜头的距离如何变化；动作、姿态或停顿透露什么。无人出镜时这些判断可适配物件与抽象形状，不强加角色。

明确画面直接呈现、可能传递的情绪与潜在含义，检查是否无意加入与歌曲、用户意图或文化语境冲突的含义。视觉隐喻是本片创作，不冒充事实或歌曲作者原意。

依照真实音频给声画锚点：重音可对应接触、落定或切换；连续节奏可推动重复、接力或运动变化；长音可容纳延展；唱句转折可改变关系或视角；渐强与停顿可安排展开、留白或释放。动作可提前预备、落在重音或有意滞后，说明理由并在实际作品听看；不要把每拍都做成闪光、震动或切镜。歌词阅读窗与原声完整优先，实际时刻沿既有 cue sheet 与项目统一排程，不新增竞争时钟。

## 审片

对照本片意图检查：画面单独是否传达预期情绪或有意的稳定；音乐段落与画面变化是否相互支持；关键动作、唱句、停顿和落点是否按真实声音成立；歌词是否可读，视觉是否无意增加误导性解释。再连续播放整段，分开记录画面、实际听审、声画同步和观众理解；无法听审或无独立观众反馈时如实标记，不能宣称共鸣已验证。留白和静态可有意成立，不能只用画面变化数量评判。

## 方法来源

灵感来源于[耶鲁音乐视频教学资料](https://teachers.yale.edu/download/units/12_01_05.pdf)：第 8 页的概念／表演／叙事分类，第 8–10 页的场面分析，第 10–12 页的观众推断及关键片段分析。资料是 2012 年的教学单元，不是行业强制标准；本文将其改写为音乐创作指导。风格索引、歌曲分析、音乐卡点、无人物适配和声画审片是本 Skill 的扩展，并非该资料原有完整模型。
